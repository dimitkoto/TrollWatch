# Продуктови решения — TrollWatch 1.0

- Платформа: Facebook само в първата версия.
- Chrome първи; Firefox е предвиден чрез споделена логика.
- Разглеждането на потвърдени маркировки е публично.
- Подаването на сигнали изисква акаунт.
- Проверка/одобрение: само акаунти с роля reviewer или admin.
- История на наблюдаваните промени се пази отделно от историята на поведението.
- Similar Profile Detection само предлага случаи за проверка; не маркира автоматично.
- Анализ на съдържанието на публикации/коментари е извън обхвата на v1.
- Report Abuse Detection е предвиден като бъдещ модул; в v1 не се твърди достъп до вътрешните Facebook репорти.
- Непотвърдените сигнали не са публични.

# TrollWatch 1.0 — Facebook Edition

Начален технически скелет на TrollWatch: FastAPI backend, PostgreSQL, регистрация, подаване на сигнали и публично четене на потвърдени маркировки.

## Обхват на този скелет
- Facebook профили, идентифицирани чрез URL и по възможност стабилен platform ID.
- Регистрация и вход с bearer token.
- Подаване на сигнали само от регистрирани потребители.
- Администраторски/проверителски роли.
- Публичен endpoint за потвърдени профили.
- История на наблюдаваните промени по профил.
- Без анализ на политическо съдържание и без автоматично публично обвиняване.

Това е стартов код, не готова продукционна система. Преди реално пускане са нужни тестове, миграции, rate limiting, CAPTCHA/anti-abuse, сигурно управление на тайни, GDPR преглед и процес за обжалване.

## Стартиране локално
1. Инсталирай Docker Desktop.
2. Копирай `.env.example` като `.env` и смени стойностите.
3. Стартирай `docker compose up --build`.
4. API документацията ще е на `http://localhost:8000/docs`.

## Първи endpoint-и
- `POST /auth/register` — регистрация.
- `POST /auth/token` — вход.
- `POST /reports` — подаване на сигнал (изисква вход).
- `GET /profiles/flagged` — публичен списък с потвърдени профили.
- `GET /profiles/{profile_id}/history` — история на наблюдаваните промени.

Първият потребител се създава като `user`. Ролята `reviewer`/`admin` трябва да се задава чрез защитена административна процедура; не се допуска саморегистрация с привилегирована роля.

## Важно за Facebook
Разширението няма гарантиран достъп до вътрешния Facebook ID или до всички промени в профила. Записваме само данни, които потребителят подава или които разширението може законно и надеждно да наблюдава. `observed_at` е моментът на засичане, не непременно моментът, в който Facebook е извършил промяната.
